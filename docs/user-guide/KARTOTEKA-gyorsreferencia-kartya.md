## 🚪 Bejelentkezés · Kilépés

- 🌐 URL: `https://kartoteka.erek.ro` (webes)
- 🖥️ Telepített: dupla-klikk a **KARTOTEKA** ikonra
- Kilépés: **Profil (jobb fent) → Kilépés**

## 🎯 Gyakori feladatok — 3 kattintás mindegyik

### 👤 Új személy felvétele
**Tagnyilvántartás** → `+ Új személy` → CNP beírása → Mentés

### 💰 Új befizetés
**Pénzügy** → `+ Új befizetés` → Személy + Összeg → Mentés

### 🌊 Új keresztelés
**Anyakönyv** → Keresztelések → `+ Új` → Személy + Dátum → Mentés

### 💍 Új házasság
**Anyakönyv** → Házasságok → `+ Új` → Vőlegény + Menyasszony + Dátum → Mentés

### ⚰️ Új temetés
**Anyakönyv** → Temetések → `+ Új` → Személy + Halál dátuma + Temetés dátuma → Mentés

### 📖 Szolgálat rögzítése
**Munkanapló** → `+ Új bejegyzés` → Kategória: Szolgálat → Alapige + Jelenlét → Mentés

### 📋 Jegyzőkönyv
**Jegyzőkönyvek** → `+ Új` → Dátum + Elnök + Napirendi pontok → Mentés → **Véglegesítés**

## 🔍 Keresés mindenhol

**`Ctrl+F`** a böngészőben a jelenlegi oldalon keres.

A lista oldalakon mindig van **keresőmező** a tetején:
- **Név, CNP, telefon** — bármire kereshetsz
- Minimum 2 karakter kell
- Részleges találatok is jönnek

---

## 💾 Biztonsági mentés — havonta legalább 1×

**Profil → Offline mentés → „Excel export most"**

Kapsz 8 Excel fájlt a gyülekezet teljes adataival.
